# 🎲 Turn Director

SillyTavern용 IC 주사위 감독 확장입니다. 숫자나 추상적인 판정표를 모델에게 넘기지 않고, 브라우저에서 굴린 결과를 짧고 구체적인 실행 명령으로 변환해 생성 직전에만 주입합니다.

## 주요 기능

- 전체 작동: 작은 UI에서 확장 실행만 ON/OFF, 설정과 사건 기록은 유지
- 답변 전략: 진실 / 선택적 진실 / 누락 / 회피 / 거짓말 / 기만
- 대형 사건: 하나가 진행되는 동안 새 대형 사건 잠금
- 소형 사건: 독립 확률, 쿨다운, 최근 영역 중복 회피
- 판독: 끄기 / 수동 / 자동
- 재생성: 첫 출력 유지 / 지정 횟수 / 통과할 때까지(안전 상한 12회)
- 판독은 별도의 저장된 Connection Profile, 재생성은 현재 RP 모델 사용
- 현재 판정과 실패 이유를 한국어로 표시

## 설치

`st-turn-director` 폴더 전체를 SillyTavern 사용자 데이터의 `extensions` 폴더에 넣고 SillyTavern을 다시 시작합니다.

일반적인 위치:

`SillyTavern/data/<사용자>/extensions/st-turn-director/`

압축 파일을 풀었을 때 `manifest.json`이 위 폴더 바로 아래에 있어야 합니다.

## 프리셋 맨 아래에 고정하기

프리셋의 가장 마지막 위치에 다음 한 줄을 넣습니다.

`{{turn_director}}`

확장이 현재 턴의 실행문을 `<Bias_Dice>...</Bias_Dice>`로 감싸 그 자리에만 삽입합니다. OOC 또는 판정이 없는 턴에는 빈 문자열이 됩니다. 설정에서 `Depth 0 system` 방식으로 바꿀 수도 있지만, 다른 하단 프롬프트보다 뒤에 있다는 보장은 고정 슬롯 방식이 가장 확실합니다.

## 사용

채팅 입력창의 작은 주사위 버튼 또는 Extensions 설정의 **Turn Director → 설정 열기**를 누릅니다.

빠른 답장 버튼을 계속 사용하고 싶다면 다음 명령만 등록하면 됩니다.

- 설정: `/td-settings`
- 판정 보기: `/td-status`
- 수동 판독: `/td-validate`
- 대형 사건 완료: `/td-major-done`
- 소형 사건 완료: `/td-minor-done`

명령은 채팅 메시지로 전송되지 않습니다.

## 권장 시작값

- 답변 전략: 필요할 때만 ON
- 대형 사건: 15–25%
- 소형 사건: 40–60%, 쿨다운 2–3턴
- 판독: OFF 또는 수동
- 자동 판독을 쓸 때: 가벼운 판정 전용 Connection Profile + 재생성 1–2회

자동 판독은 답변마다 모델 호출을 하나 더 사용하므로 느려집니다. 가장 빠른 방식은 판독 OFF이며, 외부 주사위 실행 명령 자체는 그대로 적용됩니다.

## 주의

LLM 출력을 완전히 강제할 수는 없습니다. 이 확장은 숫자 해석과 긍정적 재해석의 여지를 크게 줄이고, 선택적으로 별도 판독과 같은 주사위 재생성을 제공합니다.
